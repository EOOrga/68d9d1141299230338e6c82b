# ASS DEVEL AMENA MOYENNE VALLEE

Flutter Android app and static web landing page for local operations work at ASS DEVEL AMENA MOYENNE VALLEE HERAULT.

The Android app stores appointment bookings, patient records, staff training progress, and audit notes locally on the device. It does not use accounts, network APIs, analytics, advertising identifiers, or Android runtime permissions.

Release outputs are generated under `docs/`, with the standalone landing page packaged as `web.zip`.
